## 症状：翻页时书页错位

这本魔导书的翻页是真实的 3D 翻转。最初书叶翻到一半，纸面内容像脱了线的木偶——正反面错开半页宽，落定才 snap 回来。

## 取证：被咳嗽打断的咒语

3D 变换要生效，父级链上必须挂着 `transform-style: preserve-3d`。而给书页内容做裁切的中间层，恰好写着 `overflow: hidden`——它会把 preserve-3d **无声打断**，后代元素全部被拍平成 2D。咒语念到一半被咳嗽打断，后半段直接失效，且控制台一个警告都没有：

```css
.sheet-face   { transform-style: preserve-3d; }   /* OK */
.sheet-scroll { overflow: hidden auto; }          /* 元凶：此处之后 3D 断裂 */
```

## 和解：分层裁决

解法是把 3D 与裁切分家：翻转用的外壳保留 preserve-3d、绝不加 overflow；需要滚动的内页独立成层，自己管自己的裁切。3D 归 3D，裁切归裁切，互不过问。

## 后记

浏览器的静默降级是最难缠的反派：它不报错，只让世界悄悄变平。调试这类问题的唯一办法是**逐层二分**——把怀疑对象一层层摘掉，看 3D 在哪一层复活。本文存档，赠给下一个被拍平的人。
