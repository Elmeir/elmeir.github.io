蒸馏釜本该越炼越轻。出事那晚，它沉得像灌了铅。

## 事故现场

某次凌晨发布的蒸馏釜体积从 120MB 暴涨到 1.3GB。代码只改了几行，罪名却查无此行——典型的「层间悬案」：问题不在这一层写了什么，而在**底下哪一层封存了什么**。

## 逐层取证

镜像的每一层都是对上一层的「追加书写」：删除文件只是打了剔除标记，下层原件仍在。用 `docker history` 沿纹理逐层看下来：

```text
第六层  COPY . .          +1.1GB   ← 元凶
第五层  RUN npm install    +180MB
第四层  COPY package.json  +2MB
```

第六层的一句 `COPY . .`，把本地工作台连灰带土整个搬了进去——包括一只忘删的 `.git` 目录，里面封存着三个月前某次提交以来的全部历史。

## 教训写在结论里

蒸馏前先过筛。`.dockerignore` 便宜得像一次性滤纸：

```text
.git
node_modules
*.log
```

否则你封存的不是药剂，是整个炼金台的灰尘。发布当晚我重写了 Dockerfile：体积回落到 130MB，世界清静了——直到下一次有人手痒。

> 镜像从不替你隐瞒什么，它只是忠实地记下你搬进去的每一样东西。
